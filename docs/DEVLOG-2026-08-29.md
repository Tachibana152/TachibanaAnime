## ⑥ 代码精简：BeanUtils 字段映射

**Q：手写 setter 映射能否精简。**

- 项目共 7 处手写字段映射，全部改为 `org.springframework.beans.BeanUtils.copyProperties`
  - `AnimeServiceImpl`：`toEntity(AnimeDTO)` / `toVO(Anime)`（纯同名）
  - `AdminPostServiceImpl` / `ForumPostServiceImpl`：`toVO(ForumPost)`（同名 + 手动 `setUsername(displayName(...))`）
  - `ReplyServiceImpl`：`toVO(ForumReply)`（同名 + 手动 `setUsername`）
  - `UserVO` / `UserInfoVO`：`from(SysUser)`（纯同名）
- 每个方法加约定注释：**同名字段由 BeanUtils 自动拷贝；派生字段需手动填充；新增字段请保持两边同名**，方便后期查找

## ⑧ 头像功能（默认图 + 1MB + 超管审核）

- `sys_user` 加 `avatar`（当前头像）+ `avatar_pending`（待审头像）
- 默认头像：`OIP-C.webp` → `frontend/public/uploads/avatar/default.webp` + 后端 `uploads/avatar/`；前端 `avatarUrl(user)` 兜底
- 上传 1MB 限制（前后端双校验）：`POST /api/files/upload` 加 `type` 参数，`type=avatar` 时 `MAX_SIZE=1MB` 并存 `uploads/avatar/` 子目录；前端 `el-upload` `:before-upload` 校验
- 提交流程：`PUT /api/auth/avatar`（写入 `avatar_pending`）→ 超管审核 `GET /api/admin/users/avatar-audits` + `PUT /api/admin/users/avatar-audits/{id}`（通过转正/驳回），同步刷新 Redis 缓存
- 前端：`UserSettingsView` 头像上传（显示「待审核」提示）；`UserManageView` 头像列 + 红点角标 + 审核对话框（旧/新对照）
- 注：无法预览图片内容，按用户指定文件使用

## ⑨ 动漫评论 + 全站评论点赞

**Q：每个动画主页添加评论功能（页面最底端），全站评论增加点赞功能。**
